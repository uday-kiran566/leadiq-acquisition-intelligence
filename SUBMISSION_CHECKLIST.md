# Caprae submission checklist

- [ ] Run backend and frontend locally from a clean install.
- [ ] Test search and industry filters.
- [ ] Test lead score breakdown and data-quality warnings.
- [ ] Add a test lead and confirm it remains after restarting the backend.
- [ ] Export CSV and confirm the file opens.
- [ ] Record a 1–2 minute walkthrough using `docs/walkthrough-script.md`.
- [ ] Review and personalize `docs/interview-answers.md` and any other handbook answers.
- [ ] Include the current resume.
- [ ] Push the code to a GitHub repository if appropriate.
- [ ] Email recruiting@capraecapital.com with subject: `Full Stack Developer - Handbook Submission - Your Name`.
- [ ] Attach/provide the repository, video, and optional demo link.
