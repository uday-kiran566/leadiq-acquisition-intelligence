# 1–2 minute walkthrough video script

**0:00–0:10 — Introduce the problem**
“Hi, this is LeadIQ, a prototype acquisition lead-intelligence workspace. It helps organize potential targets and prioritize follow-up research using transparent criteria.”

**0:10–0:25 — Dashboard**
“Here are the pipeline metrics: unique companies after duplicate removal, average fit score, high-priority leads, and records needing review. These are synthetic demo records, so the scores are illustrative.”

**0:25–0:45 — Search and filters**
“I can search by company, industry, or location and filter by industry to narrow the pipeline.”

**0:45–1:05 — Data quality and score details**
“Data quality is shown separately from fit. For example, a record can have a reasonable fit score but still need review because its website is missing or its information is unverified. Clicking a company opens the scoring breakdown, so the score is explainable.”

**1:05–1:20 — Add lead**
“I can add a lead through the form. The API validates required fields and prevents duplicate company names. The new record is persisted locally in the demo data file.”

**1:20–1:30 — Export and close**
“I can export the currently displayed results to CSV. The next step for production would be integrating a trusted company-data source, relational storage, access controls, and a diligence workflow. Thanks for watching.”

## Recording checklist

- Close unrelated tabs and notifications.
- Start backend and frontend before recording.
- Use synthetic data only; do not imply these are verified real businesses.
- Show the score details, a data-quality warning, a filter/search, add lead, and CSV export.
- Keep the recording around 90 seconds.
